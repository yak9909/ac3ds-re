# ac3ds-re

『とびだせ どうぶつの森』（3DS・日本版、無印＋更新）と『どうぶつの森 ハッピーホームデザイナー』（日本版 v1.1）の解析の記録です。

## 中身

| 場所 | 内容 |
|---|---|
| `findings/` | 分かったこと（1件1ファイル）。索引は `findings/INDEX.md` |
| `topics/` | カテゴリごとに整理した「今わかっていること」 |
| `symbols/` | 関数・変数・型の名前とアドレス（IDA・Ghidra に取り込める形式） |
| `meta/` | ビルド・タグ・カテゴリ・モデルの格付けなどの台帳 |
| `docs/` | 手順書（命名規則など） |
| `tools/` | 記録と監査の道具 |
| `skills/` | 作業の手順（AI エージェント向け） |

ゲームのデータ（ROM・RomFS・IDB・デコンパイル結果）は含みません。自分で吸い出したゲームから、`symbols/` を IDA などに取り込んで使います。
