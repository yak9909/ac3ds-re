## F-182: 追加した UI 画像を絶対座標で置けた。複製元は地図の影 — `HIGH`（実機で A/B）

適用: `PATCHES/cave_add_sprite.py`

### 1. A/B の結果

`POS_X` の 1 値だけを変え、他（`POS_Y`、大きさ、索引の定数）は据え置いて比較した。

| | `POS_X` | 結果 |
|---|---|---|
| A | 0.0 | 板がある位置に出る |
| B | 160.0 | **板が動いた** |

**Picture 側の行列も、テキスト側（F-158 / F-160）と同じ配置**であることが確定した。

```
行列は 3 エントリ = 3 行 x 4。各行の第 4 要素が平行移動。
複製先が [3..6) なら
  ptr + 48 + 12  = X 平行移動
  ptr + 48 + 28  = Y 平行移動
```

**絶対値で上書きしているので、複製元がどこにあっても我々の板は同じ場所に来る。**
GUI として必要な性質を満たしている。

### 2. ★複製元は「地図の影」だった（ユーザーの同定）

観察がすべて説明できる。

| 観察 | 説明 |
|---|---|
| 暗い | 影だから |
| 半透明 | 影だから（＝アルファブレンドが効いている証拠でもある） |
| 大きい | 地図全体を覆う影だから |
| 地図やボタンより後ろ | 影は地図の下に描かれるから |
| 下画面 | 地図は下画面だから |

**「そのフレームで最初に条件 `(1,3,2)` に合ったバッチ」が地図の影だった。**
条件を変えれば別の複製元を選べる＝**レイヤーと素材を選べる**ということでもある。
