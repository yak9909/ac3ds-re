## F-220: ★★★TODO-134 段 B 完成 — 上下画面の描き分けとチャンク別の色 — `HIGH`（実機）

自前チートメニュー（TODO-134）の描画基盤。実機で確認済み。

### 上下画面の描き分け

F-210 の「実行時に対象を追いかける」仕組みを **2 系統**に増やしただけで済んだ。

```
Frame_DrawPass1040（下画面） 集め中 LOG+0x2C -> 確定 LOG+0x34
Frame_DrawPass1024（上画面） 集め中 LOG+0x94 -> 確定 LOG+0x90
```

再生を控えるケーブは既にパスの印（LOG+0x30）を見ていたので、印 1（上画面）の枝を
足すだけ。描画ケーブは「どちらの対象と一致したか」で
**スプライト表の先頭とチャンク数を .bss から選ぶ**。

実測: 発火 238 回 / 4 秒（＝約 120 フレーム x 2 画面）。
下画面 = リスト id 15、上画面 = リスト id 8。両画面に文字が出た。

### チャンクごとの色

色をリテラルに焼くのをやめ、**.bss の配列から 1 チャンクごとに 16 float 読む**。
読み出し位置は 1 チャンク進むごとに 0x40 進む（4 隅 x RGBA x 4 バイト）。

これが無いと、選択帯・黄色の未適用項目・半透明パネルのような UI が作れない。
実測: 下画面を白／赤、上画面を緑／水色に分けて 4 色とも出た。

### ★リテラルに焼いてよいのは「変わらないもの」だけ

表の先頭・チャンク数・色をリテラルに焼いていたので、**内容も枚数も色も
1 種類しか使えなかった**。UI を作るには全部を実行時に変えられる必要がある。
「動く 1 例」を作るときのリテラルは、**基盤にする段階で必ず外す。**
