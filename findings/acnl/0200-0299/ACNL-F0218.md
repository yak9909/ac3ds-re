## F-193: ★★★★★自前スプライトを独立したバッチで描画。テクスチャも独立 — `HIGH`（実機）

`PATCHES/cave_own_batch.py`。**「左上に白黒の市松模様の板が出て、背景は元のまま」**（ユーザー確認）。

### 1. 方針 — フラッシュをラッパで包む

`DrawCtx_FlushBatch(drawctx, cursor)` は `R0`/`R1` で入り、進めた cursor を `R0` で返す（F-185）。
元命令 `PUSH {R4-R8,LR}` を別番地（トランポリン）に置けば **`BL` で呼べる**
（関数末尾の `POP {R4-R8,PC}` が呼び出し元へ戻る）。

```
トランポリン:  PUSH {R4-R8,LR}     ← 元命令
              B    0x4B8364        ← 続きへ

ケーブ（0x4B8360 のフック）:
  1. BL トランポリン        ゲームのバッチをそのまま流す（カウンタが 0 に戻る）
  2. 配列[0].w0 を 3 つとも復元（F-192）
  3. 自前のテクスチャレジスタ 4 組を発行（F-191）
  4. 配列に自前スプライトだけを組む
  5. BL トランポリン        自前のバッチを流す
  6. POP {R4-R6,PC}         最後のカーソルを R0 で返す
```

### 2. ★★素通り経路で `R0` / `R1` を絶対に壊さない

`DrawCtx_FlushBatch` は **`R0` = drawctx / `R1` = cursor の 2 引数**。
判定に `R1` を使って `Mem_Copy(dst=0)` の SIGSEGV を踏んだ（`DOCS/crash_recovery.md`）。

**判定は `R6`（自分で PUSH して保存）と `R12`（元関数も作業用に使う）だけで行う。**
設置前に入口の全命令を機械的に走査し、`R0`/`R1` を書く命令が 0 件であることを確認すること。

### 3. 自前スプライトの構成

ゲーム自身の形（F-187）をそのまま使う。

| 索引 | 用途 |
|---|---|
| 行列 0..2 | 単位行列＋平行移動。行0 の w が X、行1 の w が Y |
| 色 3..6 | 4 隅（左上→右上→左下→右下）、各 (R,G,B,A) |
| 幾何 1 | (幅, 高さ, −幅/2, +高さ/2) |
| 索引エントリ [0] | w0=0 / w1=1 / w2=0 / w3=3 |

カウンタ `+36=1` / `+37=7` / `+38=2`。

**行列は単位行列＋平行移動**（F-189 の可視化で `(1,0,0,tx) (0,1,0,ty) (0,0,1,tz)` と判明）。
