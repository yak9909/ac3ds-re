## F-187: ★ゲーム自身の「色つきスプライト」を実測。構造は自前と同一だった — `HIGH`（実機フック）

`PATCHES/probe_vertex_color.py`（`0x4B8348` と `0x73CD1C` の 2 点フック）で、
**ゲーム自身が頂点カラーの索引経路を使う瞬間**を捕獲した。

### 1. 索引経路は普通に使われている

**3 秒間で 279 回。** 索引エントリも 279 回すべて捕獲できた。
「この素材系統では色が使われていない」という仮説は否定された。

### 2. 捕獲した 1 例

```
*(drawctx+1636) = 3.0        作られた色の索引
新しい +37 = 7               行列 0..2 の直後に色を 3..6 へ積み、+4 した
索引エントリ = 32FF6380（= 索引配列の先頭 = エントリ [0]）
  w0（行列の索引）  = 0.0
  w1（自分の幾何）  = 1.0
  w2（追加幾何）    = 0.0
  w3（★色）        = 3.0
```

**`色の索引 = 行列の索引 + 3`。** 色は行列 3 エントリの直後に置かれる。

### 3. ★自前スプライトと構造は同一だった

| | 行列 | 色 | w3 | 自分の幾何 | 追加幾何 |
|---|---|---|---|---|---|
| ゲーム | 0..2 | 3..6 | 3.0 | 1 | 0 |
| 自前 | 3..5 | 6..9 | 6.0 | **3** | **2** |

`w3 = w0 + 3` の関係も、色を行列の直後に置くことも同じ。
**違うのは `w1` / `w2`（幾何の索引）だけ。**
自前は複製元の幾何を 2 エントリぶんコピーして 2,3 に置いていた。

### 4. 次に確かめること

**幾何をコピーせず、複製元の幾何をそのまま共有する**（`w1=1, w2=0` にする）。
それで色が効けば、原因は幾何のコピーにある。
大きさの指定は一時的に失われるが、色の帰属が確定すれば戻せる。

道具: `PATCHES/probe_vertex_color.py`（`install` / `read` / `uninstall`）
