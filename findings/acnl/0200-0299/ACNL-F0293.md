## F-270: ★★★★DrawBegin1 は **テクスチャユニットを全部無効にする**。自前記録では立て直さないとテクスチャが読まれない — `HIGH`（静的 + 過去の実測列）

自前記録の設計（F-259 以降）に残っていた穴。**これは `OWN_TEV` とは独立の問題である。**

### `sub_4D72C4`（DrawBegin1 の中）が出すもの

```c
*a2      = 0;         a2[1] = 131183;    // 0x0002006F  reg 0x06F mask 2 = 0
a2[2]    = 0;         a2[3] = 2097280;   // 0x00200080  reg 0x080 mask 2 = 0
a2[4]    = 0;         a2[5] = 0;         // ヘッダ 0 = 何も書かない（詰め物）
a2[6]    = 4096;      a2[7] = 721024;    // 0x000B0080  reg 0x080 mask 0xB = 0x00001000
```

reg `0x080` = `GPUREG_TEXUNIT_CONFIG`。ビットの意味は `sub_7269BC`（3D 側の同種処理）が
値を組み立てている式から読める。

```c
(tex0有効) | (tex1有効 << 1) | (tex2有効 << 2) | (… << 8)
          | (… << 10) | (… << 13) | 0x1000
```

**`sub_4D72C4` が書く値は `0x00001000`。bit0〜2 が 0、つまり
ユニット 0/1/2 がすべて無効になる。**

### なぜ今まで問題にならなかったか

旧経路（`cave_draw_topmost.py` / `cave_draw_sprites.py`）は
**ゲームの replay 列に相乗り**していたので、直前のペインが有効化した
ユニット 0 の状態をそのまま借りられていた。

自前記録（F-259 以降）は **`DrawBegin1` の直後から始まる**。
そこではユニットが無効にされたばかりなので、
`0x082` / `0x083` / `0x085` / `0x08E` でアトラスを結び付けても**読まれない**。

### 直し方

自前のテクスチャレジスタ列の**先頭**に reg `0x080` を足した。

```
reg 0x080 = 0x00011001   (mask 0xF)
  bit0  = ユニット 0 有効
  bit12 = 0x1000   （ゲームが常に立てる）
  bit16 = 0x10000
```

値は推測ではなく、**F-124 で実機から捕獲したグリフ 1 枚ぶんのコマンド列**
（`RE/FINDINGS.md` の「1 グリフ分のコマンド列（`T_slsh` "/"、86 ワード）」）に
現れる実値である。そこでは `mask 0xB` と `mask 0x4` の 2 回に分けて
同じ `0x00011001` を書いていた。`mask 0xF` で 1 回書けば最終状態は同じになる。

捕獲列にはこの直後に `0x08E` / `0x085` / `0x082` / `0x083` が並んでいて、
**ユニットの有効化はテクスチャの結び付きと一緒に出すもの**だと分かる。
だから TEV 列（F-269）ではなくテクスチャ列の側に置いた。

### 検証

`build_q` のテクスチャ列は 5 組 10 語になった。

**独立その 1**（生成語から LDR のリテラル参照先を復号）

```
語168 LDR->語378 = 0x00011001   語379 = 0x000F0080   ← 新規
      LDR->語380 = 0x00400040   語381 = 0x000F0082   64x64
      LDR->語382 = 0x00000000   語383 = 0x000F0083   ニアレスト
      LDR->語384 = 0x0453B0A0   語385 = 0x000F0085   (0x329D8500-0x10000000)>>3
      LDR->語386 = 0x00000009   語387 = 0x000F008E   LA4
```

**独立その 2**（IDA。相対位置を保ったまま `0x8369A0` と `0x836CE8` へ当てて逆アセンブル）

```
0x8369a0 LDR R1, loc_836CE8   / STR R1, [R5],#4
0x8369a8 LDR R1, loc_836CEC   / STR R1, [R5],#4
…（全 10 対、リテラルは 4 バイト間隔で連続）
```

直後に元バイトへ復元し、`NCCH/exefs/code_runtime.bin` と一致を確認。
監査: 総異常 0 件・重なりなし。`CAVE_Q` は 382 → 388 語。
