## F-194: ★★★UV の座標系を確定。アトラスから切り出せる — `HIGH`（実機で 3 段階の A/B）

追加幾何エントリ（索引エントリの `w2` が指す先）の 4 float が UV。

### 1. 形式

**`(u0, v0, u1, v1)`。`v0` が上端、`v1` が下端**（v は上が 1 = 反転している）。

| 値 | 指す範囲 | 実機の見え方 |
|---|---|---|
| `(0, 1, 1, 0)` | テクスチャ全体 | ゲーム自身のエントリで観測 |
| `(0.0, 1.0, 0.5, 0.5)` | **左上象限** | **真っ白**（輝度 15） |
| `(0.0, 0.5, 0.5, 0.0)` | 左下象限 | 灰色（輝度 5） |

### 2. 検証の作り方

**4 象限で輝度を変えたテクスチャ**（左上15 / 右上10 / 左下5 / 右下0）を使った。

市松模様のままだと「UV が効いていない」と「象限を間違えた」を区別できない。
**単色になれば切り出し成功、複数ブロックが見えれば失敗**、と一目で分かる形にしたことで
2 手で座標系が確定した。

### 3. ★[0].w0 の復元との順序

追加幾何に索引 0 を使う場合、**F-192 の復元を先に済ませてから UV を書く**こと。
順序を逆にすると復元が UV を上書きしてしまう。

### 4. これで揃うもの

アトラスに文字や図形を並べ、**1 つずつ UV で切り出して位置・大きさを変えて並べられる**。
ビットマップフォントの基本形が成立した。
