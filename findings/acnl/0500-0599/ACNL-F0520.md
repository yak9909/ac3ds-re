## IDA-opus-5.5-F011: 灯り・プレイヤーの家（テント本体・柵・ポスト）まで全部を薄い青にできた。環境光に関係なく同じ明るさ（2026-09-23、HIGH（静的＋実機で表示確認））

解析ソフト: IDA / 解析モデル: opus-5.5。利用者の依頼「街灯の灯り部分も含めて色を変えられるか」「環境光に影響しないが本当か、奥の
プレイヤー 1 の家（テント）も変えて確かめる」。選択中の建物の表示に使う予定なので、家本体・柵・ポストのすべてを青くする必要がある（利用者）。
道具 `tools/models3d/tint_multi.py`（apply / color / restore、元値 `work/evidence/models3d/tint_multi_state_round{1,2,3}.json`）。

### 1. 段 5 が「空き」と言える 3 つの形（実機の値）

| 形 | 段 5 の値 | 例 |
|---|---|---|
| 前段をそのまま（Replace） | 入力 0x0E1F0E1F、合成 0 | 街灯の柱、家の各部 |
| 前段をそのまま（別の書き方） | 入力 0x033F033F、合成 0（RGB の入力 0 = 前段、オペランド = 色） | 家のモデル +0xB28 の 2 材質 |
| 定数色アルファ 0xFF の Interpolate | 入力 0x033F0EFD、オペランド 0x300、合成 4、選択した定数色のアルファ 0xFF → 結果は前段そのもの | 街灯の灯り（定数色 0xFF001D43） |

判定は「RGB の合成が Replace で入力 0 が前段・オペランド 0 が色」または上の Interpolate。置き換えるときは RGB 半分だけ書き換え、
アルファの入力・オペランド・合成はそのまま残す（切り抜きを保つ）。

### 2. 共有 TEV の写しと +40

建物の TEV ブロック 244 B の +40 は、直後（+244）のライティング参照表への**相対ポインタ（実測 0xCC）**。写しへ動かすときは付け直す
（ゲームの複製 `gfx_ResMaterial_CopyForInstance` も +40 だけ付け直している）。街灯では材質の `a3[17]`（ライティング）は共有資源のままで、
色の部分の +648 を変えても影響しない。プレイヤーの家の材質は `a3[10]`〜`a3[20]` がすべて同じブロック（家専用。P2 の家は別）。

### 3. 書き出し関数と、プレイヤーの家の構成

- 描画 `sub_494B4C` は **材質 +28（モデル）→ +0x1EC（= 492）の MaterialActivator の slot 3** を、材質が前回と変わったときだけ呼ぶ（`0x494C14`）
- 家のモデルは全部 **SimpleMaterialActivator（slot 3 = 0x4A17B8、事前に作ったコマンドを流すだけ）** → そのモデルの Activator だけ
  vtable の写し（slot 3 = 汎用 0x49C08C）へ替える（IDA-gpt-6-astra-F002 と同じ）。写しは `.bss` の余り 0xAF26A0〜
- **プレイヤーの家は 3 つの持ち主に分かれている**:
  - 家の実体（AcStrcPlayerHouse）の +0x2FC のモデル → **柵**（利用者が「柵が変わった」と確認）。
    **訂正（F012）**: +0xB28 / +0xBD8 / +0x11C0 は家のブロック（0x5DC）の外で、隣の住民の家 0x0B のモデルだった
  - 家の実体 +0x5A4 の **`hobj::Tent`**、その +0x274 の SkeletalModel → **テント本体**
  - 家の実体 +0x5D8 の **`AcStrcPost`（別の実体）**、その +0x2FC の SkeletalModel → **ポスト**
  最初は家の実体のモデルだけを変えて「テントが変わらない」と見えた。実体の中の他オブジェクト（Tent・Post）まで辿る必要がある

### 4. 実機の結果（画像 `work/evidence/screens/tint_20260923/`）

- round 1（街灯 2 材質＋家の +0x2FC）: **街灯は灯りを含めて全体が青**（`multi_b0.png`）。テントは不変
- round 2（家の実体の 4 モデル）: テントは不変、**柵が変化**（利用者の指摘）（`multi2_b0.png`）
- round 3（＋Tent・Post）: **テント本体・柵・ポスト・街灯すべて薄い青**（`multi3_b0.png`）。夜の暗い場面でテントと街灯がほぼ同じ明るさの
  水色 → 環境光に引きずられない
- restore で全部元の色へ（`multi3_restored.png`）。41 か所の値が元どおり、`.bss` の余りも 0

残り: 建物の種類ごとに「どの持ち主がどのモデルを持つか」の表（家は 3 か所）、常用化（ヒープ上の写し、GPU 参照終了）、
段 5 が本当に使われている材質（上の 3 形以外）への対応、影などの別パス、モデルビューアの自前モデル。
