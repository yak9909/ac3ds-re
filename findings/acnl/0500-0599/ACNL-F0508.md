## IDA-opus-5.5-F023: 半透明は描画層で後ろへ回し深度は書く／役場の旗とチケットマシン／もとから半透明の材質のアルファ／一枚絵の合成の調査（2026-09-24、HIGH（実機の比較画像）／MEDIUM（一枚絵は設計のみ））

解析ソフト: IDA / 解析モデル: opus-5.5。利用者の依頼（実機 Suspend・役場の前、Chokistream 起動済み）。画像 `work/evidence/screens/layer_20260924/`。

### 1. 半透明にすると奥の物が前に出る
- `Scene_DrawLayers 0x4EB840`（V2-F024）: 層 0〜3 の順に描き、層 = **Material+8 の ResMaterial +32 の下位バイト**。同じ層は積んだ順
- 建物の材質は層 0（不透明と同じ流れ）。gohan は深度を書かない半透明にしていたので、同じ層であとから描かれる奥の物が上に出ていた
- 実機: 共有される種類（街灯 0xC3 等）は M+8 が資源の ResMaterial（全実体で同じ）、役場は M+8 = 実体の写し
- 対策（gohan `403db94`）: 半透明にした材質の M+8 +32 を **1**（不透明の後）、**深度は書いたまま**。共有される種類は同じ種類の他の建物も層 1 になるが不透明のままなので見た目は同じ。戻すときは undo で戻る
- 比較（役場、定数アルファ 0x90）: 深度を書かない → 柱・窓の周りで奥の面が透けて重なる、書く → ほぼ一枚の見え方（`cmp_depthoff_vs_on.png`）
- `+300`（元 0x80000000）を 0 にしないとブレンドが効かず暗くなるだけ（`cmp_300zero_vs_keep.png`）→ F002 の 0 は必要

### 2. 役場のふるさとチケットマシンと旗
- チケットマシン = `AcHomeTicketMachine`（profile 0x9E）。**`BsStrcMgr_SpawnStructures 0x6DE198` が役場（Building_IsOffice）のとき、役場の位置＋ `sub_15041C` のずれで作る別プロセス**（実機: 役場 (2416,944)、機械 (2340,996)）。役場からのポインタは無い → 同じ管理役の下の兄弟から探す
- 旗 = `BsFlag`（ScStage 直下の管理役）。**役場 +0x4D0 が指す**。+0x24 に nw::gfx::Model（ほか FuncNode）
- 実機: 両方のモデルの材質を同じ方法で変えると薄い青になった（`4_ticket_flag_tint.png`）、戻して確認（`5_restored.png`）

### 3. もとから半透明の材質（たいまつ・たき火のグロー等）
- 定数アルファのブレンド（src = CONSTANT_ALPHA）に置き換えると画素ごとのアルファが捨てられ一律になる（利用者報告）
- 対策: ブレンドの式（reg 0x101 = frag +328）が RGB で ONE/ZERO 以外なら**ブレンド・深度・層に触らず**、TEV の最終段（空き段か詰めた段のときだけ）を
  A = MODULATE(前段.a, 定数.a)、RGB = MULTIPLY_ADD(前段, 1−定数.rgb, 定数.rgb)（強さを掛けた色でスクリーン合成）にする。定数.a = 揺れる不透明度。
  最終段を置き換える形（6 段すべて使用）では色だけ変えてアルファに触らない。検査は verify_highlight.py の PICA 合成器の小模型
- 設置プレビューも同様（色は合成しない）。実機での見た目は未確認

### 4. 一枚絵として合成する方法の調査（未実装）
- **別バッファ＋合成**: PICA200 は描画先（色バッファの番地）を途中で替えられるので、層 0 のあとに「深度バッファは本物のまま、色だけ別の VRAM バッファ」で建物を描き
  （深度テスト・書き込みあり → 建物の一番手前の面だけが残る）、戻してから全画面の板を定数アルファで重ねれば一枚絵になる。
  ただしテクスチャで深度を読めない（深度テクスチャが無い）ので、Z を合わせる役は「本物の深度バッファを共有して描く」ことで果たす。
  必要なもの: 400x240 の RGBA8 バッファ（約 384 KB の VRAM、左右の目で 2 回）、Scene_DrawLayers の層 0 と 1 の間でのフック、描画先の切り替えと復帰のコマンド、全画面の板。重い
- **深度だけの先描き（推奨）**: 同じ見た目を別バッファ無しで作れる。建物を 2 回描く。1 回目 = 色を書かず深度だけ書く（reg 0x107 の色マスク 0、深度書き込み 1）、
  2 回目 = 深度テスト LEQUAL・深度書き込みなし・ブレンド。1 回目を層 1、2 回目を層 2 に置けば順番が保証される（層 2 は romfs で 4 材質のみ）。
  2 回目用に同じ資源からもう 1 体のインスタンスを作り（設置プレビューと同じ手順）、毎フレーム行列（骨）を元の建物から写す。
  元の建物の材質は深度だけ（frag +284/+288 の 0x107 を色マスク 0・書き込みバイトも含めて書く）にする
- どちらも実機未確認。まず「深度だけの先描き」を試すのが安い
