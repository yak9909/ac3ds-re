## 結論

再解析で確認。対象ビルドの Layout 描画には次の三つの呼出し経路と二本のリストがある。確度 MEDIUM：各パスの引数・リスト参照と、生成処理・vtable・記録/再生/解除処理が独立に整合する。実機操作はしていない。

| パス | Frame 関数 → LayoutMgr 関数 | display | ビューポート | リスト | 処理 |
|---|---|---|---|---|---|
| 上左目 | `0x1B71C4` → `0x566DF8` | `0x400` | 400×240 | `mgr+0x04` | 記録巡回 → 再生。ここでは解除しない |
| 上右目 | `0x1B72E4` → `0x5692B0` | `0x410` | 400×240 | `mgr+0x04` | 再生 → 上リスト解除 |

記録巡回は各 Layout の記録メソッドを呼ぶことで、全 Layout のコマンドを毎回作り直す意味ではない。三パスの存在と各処理は確認したが、フレーム内の実行順そのものを関数表の順から断定しない。

## 根拠

- 一次証拠：`_local/evidence/16/ida-primary.txt`、`ida-followup.txt`、`ida-dispatch-submit.txt`。疑似Cだけでなく命令とデータを採取した。
- `0x569198..0x5691AC` は生成した mgr の先頭へ mgr vtable、`+0x04` と `+0x10` へ同じ LayoutList vtable を設定する。リスト初期化 `0x126508` は `+4/+8` をゼロにする。`0x133A64` は同じ大域 mgr を返す。
- `0x566E08` の `ADD R0,R4,#4` と `0x566E0C` の vcall は上リストの記録巡回。`0x566E14` は幅 `0x190`、`0x566E10` は高さ `0xF0`。`0x566E28` で display=`0x400`。`0x566E2C` は元バイトも NOP で、次の `0x566E30` へ fall-through する。
- `0x5692BC` は幅 `0x190`、`0x5692C4` は display=`0x410`、`0x5692C8` は `mgr+4`。`0x5692CC` の再生呼出し後、`0x5692D8` で `0x133B20` へ分岐する。記録巡回の呼出しは無い。
- `0x568FA8` は `mgr+0x10` を記録巡回へ渡す。`0x568FB4` は幅 `0x140`、高さは `0xF0`。`0x568FC0` が読むリテラル `0x568FD8` は `0x401`。`0x568FC8` は下リストを再生し、`0x568FD4` が同じリストを解除する。
- LayoutList vtable `0x900554` の `+8` は `0x566EA0`。同関数は `list+4` から `node+8` を辿り、各 node の vslot `+0x14` を呼ぶ。Layout vtable `0x900608` の当該スロットは `0x5686D4`。同関数の `0x568704..0x56870C` は記録要求 `Layout+0x11D` を検査する。
- 再生巡回 `0x566E38..0x566E60` は同じリンク順に `node+0x134=display` を書き、vslot `+8` を呼ぶ。Layout の当該スロット `0x900610` は `0x5682DC`。
- `0x133B30..0x133B48` は全 node の `+4/+8`、list の `+4/+8` をゼロにする。上リストの head/tail は `mgr+0x08/+0x0C`、下は `mgr+0x14/+0x18`。
- `0x5692DC` は寸法から GPU コマンド列を作り `0x56950C/0x56951C` で送る。一方、投影は `0x567BC8` で `Layout+0x10` を `0x73BAC0` へ渡し、そこから幅/高さ `Layout+0x28/+0x2C` を読む。行列は `0x567C84/0x567C88` で `Layout+0x30` の DrawInfo へ設定され、再生時の `0x5683C4` → `0x4B8C34` → `0x4D6C90` で `Layout+0x34` の16語が出る。パスの寸法と Layout の投影は別である。
- `0x568374` は `LDRBEQ R1,[R5,#0x20]`、ここで `R5=Layout+0x100`。従って条件バイトは **`Layout+0x120`**。`0x400/0x410` かつ同バイトが1なら `+0x124` を読み、`0x400` 側だけ符号反転する。旧記録の `+0x320` ではない。`+0x134` は画面別オフセットの選択に使われ、再生可否は記録長 `+0x108` が決める（シザー発行はその判定より前）。
