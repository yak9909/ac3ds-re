## F-169: ★★★自前テクスチャを自前サイズの四角形に貼れた。TODO-120 達成 — `HIGH`（実機で視認）

適用: `PATCHES/cave_own_texture.py`

### 1. 結果

時計の「分」の 1 文字目の位置に、**自前で用意した市松模様の四角形（80x80）**が出た。

- テクスチャの実体は `g_GfxAllocator->Alloc` で確保した `0x329D9600`（F-165/F-166）
- 中身は**こちらが 8x8 タイル + Morton 順で書いた A4 の市松模様**
- 大きさは `c[0x40+1]` で 80 x -80 に指定
- UV は 0..1 全域

**「GPU 可視メモリの確保」「テクスチャの詰め方」「任意サイズの四角形」が 1 本に繋がった。**

### 2. 変更を最小にした

**フォントと同じ A4 形式・128x128 のまま**、`reg 0x085` だけを自前バッファへ向けた。
形式も寸法も変えていないので、TexEnv もブレンドもゲームの設定のまま使える。

**位置（`c[0x40+1]` の X, Y）は据え置いた。** F-168 の教訓。

### 3. 書き換えた 7 ワード（ゲーム自身のコピー `R9 + 0x60` 起点）

| ソースのワード | 内容 | `R9` からのオフセット | 入れた値 |
|---|---|---|---|
| 40 | `reg 0x085` テクスチャ物理 >> 3 | `+0x100` | `0x0453B2C0` |
| 60 | UV u0 | `+0x150` | `0.0` |
| 62 | UV v0 | `+0x158` | `1.0` |
| 63 | UV u1 | `+0x15C` | `1.0` |
| 64 | UV v1 | `+0x160` | `0.0` |
| 65 | 幅 | `+0x164` | `80.0` |
| 66 | 高さ | `+0x168` | `-80.0` |

ワード番号は install 時に検証している
（ワード37 が `0x000F008E`、ワード41 が `0x000F0085`、ワード61 が `0x00FF02C1`）。

**ケーブは `(オフセット, 値)` のテーブルを回す形にした。**
値だけ更新すればコードを書き換えずに済み、新しいケーブ番地を消費しない。

### 4. テクスチャの詰め方（F-124 / F-125 の再確認）

```
8x8 タイル。タイルは行優先
タイル内は Morton 順  i = x0|y0<<1|x1<<2|y1<<3|x2<<4|y2<<5
A4 は 4bit/texel = 2 texel/byte。下位ニブルが先
n = (ty * (W/8) + tx) * 64 + i
```

この手順で書いた 128x128 A4（8192 バイト）がそのまま正しく表示された。

### 5. これで書けるようになったもの

| やりたいこと | 手段 | 追加で要るもの |
|---|---|---|
| **半透明の単色矩形** | バッファを全部 `0xF` にして `reg 0x0F3` で色と alpha | なし。今すぐ書ける |
| **自前ビットマップフォント** | グリフごとに UV を変えて複数枚 | `reg 0x228` = 6 * 枚数と、定数を枚数分積む |
| **SD から読んだ画像** | RGBA8 か RGB565 で置く | `reg 0x08E`（形式）と `reg 0x082`（寸法）の変更。
アルファのみ前提の TexEnv も要調整 |

**残る本質的な課題は「TextBox に依らない発行点」だけ**（TODO-115）。
現状は既存のテキスト描画に相乗りしているので、
対象の TextBox が描かれる場面でしか出せない。
