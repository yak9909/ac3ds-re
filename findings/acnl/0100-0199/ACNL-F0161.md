## F-123: ★★TODO-87 — 影のテクスチャの実体を特定し、書き換えて画面に反映させた

confidence: **HIGH**（実機。A/B を 3 回切り替えて目視確認）

### 1. テクスチャの素性

`0x085 TEXUNIT0_ADDR1 = 0x0460EC90` から辿った。

| 項目 | 値 |
|---|---|
| レジスタ値 | `0x0460EC90` |
| 物理アドレス | `<<3` して **`0x23076480`** |
| **仮想アドレス** | **`0x33076480`**（**`virt = phys + 0x10000000`**） |
| 大きさ | **32 × 32**（`0x082 TEXUNIT0_DIM = 0x00200020`） |
| フォーマット | **ETC1**（`0x08E TEXUNIT0_TYPE = 0x0C`） |
| データ量 | **512 バイト** = 64 ブロック × 8 バイト |

仮想アドレスは総当たりで決めた。候補 `phys-0x10000000` / `phys-0x0C000000` / `phys` /
`phys-0x20000000+0x14000000` はすべて `0xFF`（未マップ）で、
**`phys+0x10000000` だけが実データ**だった。
ゲームのヒープが `0x30000000`〜`0x33000000` にあることとも整合する。

### 2. `0x083 TEXUNIT0_PARAM = 0x00003326` の解読

| ビット | 値 | 意味 |
|---|---|---|
| bit1 / bit2 | 1 / 1 | 拡大・縮小フィルタ = **LINEAR** |
| **bit5** | **1** | **ETC1 フラグ**（フォーマット `0x0C` と整合） |
| bits 8-9 | 3 | wrap T = **MIRRORED_REPEAT** |
| bits 12-13 | 3 | wrap S = **MIRRORED_REPEAT** |

**★これで F-121 の観察が説明できた。** 行列の拡大成分を 2 倍にしたとき
ユーザーが見た「**横に伸びた分、影が上下からループするように描画される**」は、
**wrap が MIRRORED_REPEAT だったから。**

### 3. ★書き換えて画面に反映させた

`scratchpad/tex_patch.py` で 1 ブロックおきに 0 を書き込み（非ゼロ 64 → 32）。
**パッチ類はすべて外し、ゲーム本来の描画だけが動く状態**で A/B を 3 回切り替えた。

ユーザーの報告:

> ほとんどのオブジェクトに縞模様が現れているのを確認しました。
> 一部オブジェクトの影はぼやけていて縞模様が入っているかよくわかりません。
> 縞模様が入っただけで、欠けていたりなどはしていないように見えます。

**両方の細部が理屈と一致する:**

- **ぼやけて縞が見えない影がある** … フィルタが LINEAR なので、
  遠くの小さい影では 4×4 ピクセルの縞が平滑化されて潰れる
- **欠けずに縞になるだけ** … ETC1 の全ゼロブロックは透明ではなく
  **基準色 0 ＋ モディファイア +2 の暗い色**になる。だから穴が空かず濃淡の縞になる

**ゲームがこのバッファを毎フレーム上書きし直すことも無い**（15 秒走らせても
非ゼロ 32/64 のまま）。一度書けば持続する。

### 4. 意味

**当初目標「テクスチャの描画」に対して、貼られる絵そのものを握れた。**
残りは「ETC1 で自前の絵を作る」か「フォーマットを変える」かの選択だけ。

### 5. ★フォーマット変更の余地（未実施）

32×32 で **512 バイトに収まる非圧縮フォーマット**がある:

| フォーマット | 値 | bpp | 32×32 のサイズ |
|---|---|---|---|
| `GPU_L4` | `0xA` | 4 | **512 バイト** ✔ |
| `GPU_A4` | `0xB` | 4 | **512 バイト** ✔ |
| `GPU_L8` / `GPU_A8` | `0x7` / `0x8` | 8 | 1024 バイト（はみ出す） |
| `GPU_RGBA8` | `0x0` | 32 | 4096 バイト（はみ出す） |

**`L4` か `A4` なら現在の 512 バイト枠にそのまま収まる**ので、
隣接データを壊さずに任意の 32×32 グレースケール画像を出せる。
そのためには `0x08E` を `0x0A`/`0x0B` に、`0x083` の ETC1 フラグ（bit5）を落とす必要がある。
これらはカテゴリ設定ブロックの一部なので、
**自前テンプレート（F-122）側で書き換えれば済む。**

### 6. 復元

原本 512 バイトは `scratchpad/shadow_tex_orig.bin` に保存済み。
`scratchpad/tex_patch.py` の `MODE="restore"` で戻る。**復元済み。**
