## F-126: ★★★TODO-94 達成 — UI 層（`nw::lyt::TextBox`）に自前の 2D テキストを出した

confidence: **HIGH**（実機。住民名が `あんこ` → `テスト` に変わることを目視確認）

### 1. ★`nw::lyt::TextBox::SetString`

`nwlyt_TextBox_SetString`(`0x4BACBC`) = `SetString(this, wchar_t* str, dstIdx, len)`。
`nwlyt_TextBox_Ctor`(`0x4BB2A4`) がリソース文字列を渡して呼ぶことから同定。

**TextBox のレイアウト:**

| offset | 内容 |
|---|---|
| `+212` (`0xD4`) | 文字列バッファ `wchar_t*` |
| `+224` (`0xE0`) | 非 0 でないと即 return（フォント？） |
| `+248` (`0xF8`) | バッファ長（バイト）。**`/2-1` が最大文字数** |
| `+250` (`0xFA`) | 現在の文字数 |
| `+254` (`0xFE`) bit0 | 更新フラグ |

vtable は `vtbl_nw_lyt_TextBox`(`0x8FC07C`)。

### 2. ★バッファへの直接書き込みは効かない

`this = 0x32D07674` のバッファへ `"AC"` を書いて走らせたら、
**次に読んだときには `"02"` に戻っていた。**
ゲームが `SetString` で再設定するため。

**→ `SetString` 自体をフックして引数を差し替える必要がある。**

### 3. ★実装（`PATCHES/cave_textbox.py`）— わずか 9 ワード

```asm
LDR  R12, =TARGET_THIS    ; 対象の TextBox
CMP  R0, R12
BNE  pass                 ; 違えば素通し（他の UI は無傷）
  LDR R1, =MYSTR          ; 自前の文字列
  MOV R3, #len
pass:
PUSH {R4-R6,LR}           ; 元の 1 命令
B    0x4BACC0             ; 続きへ（LR は変えていないので戻り先は同じ）
```

`SetString` の先頭 1 ワード（`PUSH {R4-R6,LR}` = `0xE92D4070`）を `B ケーブ` に差し替える。

**結果: 住民の名前欄が `あんこ` → `テスト` に変わった。**
（名前は会話更新時に再設定されるので、話しかけ直すと反映される）

### 4. ★トレースで差し替え先を選ぶ

`SetString` の呼び出しを 16 バイト × 64 件のリングバッファへ記録するケーブ
（`MODE="trace"` → 走らせる → `MODE="dump"`）。
CLAUDE.md の「トレース用ケーブ」の形そのまま。**45 秒で 81 件、20 個の TextBox が取れた。**

| `this` | 容量 | 文字列 | 正体 |
|---|---|---|---|
| `32D20788` ほか 3 個 | **256 文字** | `''` | **会話本文** |
| `32CFEC60` / `32CFEAE0` | 21 文字 | `きんのオノ` | アイテム名ポップアップ |
| `32D20220` | 9 文字 | `あんこ` | **住民名**（今回の対象） |
| `32D07674` ほか 3 個 | 2 文字 | `39` | 時刻か日付 |
| `32EE06F4` ほか多数 | 0 文字 | `WWWWWW` | バッファ未確保（非表示） |

**★`cap = 0` の箱は `+212` が未確保で `SetString` が即 return する。** 画面には出ない。
最初に選んだ `0x32D07674`（`"02"`）が見えなかったのも、
表示されていないメニューの要素だったため。

**推測で対象を選ばず、トレースして実データから選ぶべきだった。**

### 5. ★2 つの描画方式の比較

| | 影パイプライン方式（F-122〜125） | **UI 層方式（F-126）** |
|---|---|---|
| 座標系 | ワールド空間の地面 | **画面座標のオーバーレイ** |
| フォント | 自前 8×8 ビットマップ | **ゲーム内蔵フォント（日本語可）** |
| 文字数 | 4 文字／行（32px 幅） | TextBox の容量まで（最大 256 文字） |
| 実装量 | **4560 バイト**のコマンド列 | **9 ワード**のケーブ |
| 自由度 | 位置・大きさ・色・画像すべて自由 | 既存の箱の位置に固定 |

**用途が違う。** 任意の絵を任意の場所に出すなら影方式、
文字を確実に読ませるなら UI 層方式。

### 6. 制約と次

- `TARGET_THIS` は**ゲーム再起動で変わる**。トレースで取り直すこと
- `TARGET_THIS = 0` にすると全 TextBox を差し替える（未検証。メニューが壊れる恐れ）
- **256 文字の会話本文（`0x32D20788` ほか）を乗っ取れば長文を喋らせられる**
