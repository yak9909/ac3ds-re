## F-283: シミュレータ相当の UI へ作り直した（美咲フォント・アニメーション・項目型）— `HIGH`（ビルド済み・未適用）

利用者の指摘 3 点に対応し、`Plugin/CTRPF-GUI-Simulator` の設計を C++ へ写した。

| 指摘 | 対応 |
|---|---|
| 十字キーの移動が速すぎる | `CONTROL_REPEAT`（**200ms 長押しで 60ms 間隔**）を実装 |
| スライドパッドを無効に | 入力は `Key::DPadUp/Down/Left/Right` **だけ**を見る。`CPad` は一切見ない |
| シミュレータと同じ操作・フォント | 美咲ゴシック第2 8px（日本語）／寸法・色・所要時間をそのまま移植 |

### ★フォント — グリフを実行時にアトラスへ焼く

美咲ゴシック第2 はシミュレータで **361 字**使う。
アトラスは 128x128 の **16x16 = 256 マス**しか無い（確保が 0x4000 まで。F-221）ので、
静的には入らない。

そこで **使った字だけを実行時に焼く**（`GuiRender` のグリフキャッシュ）。

- マス (15,15) は塗り潰し専用。残り 255 マス
- 符号位置 → マスの対応は 512 枠の開番地ハッシュ
- 焼いたら **そのマスの 64 バイトだけ** `svcFlushProcessDataCache` する
- マスが尽きたら全部捨てて焼き直す（1 フレームちらつくが破綻しない）

`MisakiGothic2nd8::GetGlyph` が返す `rows`（LSB が左端）を
8x8 のモートン順へ並べ替えて書く。UTF-8 の読み進めは `NextCodepoint` を使う。

### ★チャンクの無駄を減らす — 矩形と文字を分けて積む

色はチャンク（7 枚）単位でしか変えられない（F-280）。
10 行 x 20 字ぶんの文字を「描いた順」で詰めると、行ごとに色が変わるたび
7 枠を食い潰してしまう。

そこで **矩形は並び順のまま、文字は色ごとにまとめて**積むことにした。
**文字どうしは重ならない**ので、順序を変えても見た目は変わらない。

### `.bss` を大きく取り直した（F-283 時点）

10 行 x 20 字 + 説明 + 枠で **300 枚を超える**ので、表を作り直した。
走査で `0x9B0000-0x9C0000` は全部ゼロ、指す語も全部「連続した数値表」の誤検出だった。

```
0x9B0D00  LOG         0x100
0x9B0E00  COLORS_BOT  0x1000   64 チャンク
0x9B1E00  COLORS_TOP  0x1000   64 チャンク
0x9B2E00  TABLE       0x1400    64 枚（下画面）
0x9B4200  TABLE_TOP   0x9000   460 枚（上画面）
0x9BD200  NODE_TOP / VTBL / NODE_BOT / MATBUF / RING / MATCMD
0x9BDD00  （予備。0x9C0000 まで）
LIST_SIZE = 0x10000（65536）
```

**枠が足りることを数で確かめた。**

```
チャンク上限で書ける枚数 = 64 x 7 = 448 ≦ 表 460 枚          OK
記録リストの見積り = 448 x 約127 = 56,896 バイト < 0x10000    OK
```

どちらも**上限どうしの比較**なので、内容がどう増えても破綻しない。

### 組み込み後の自己診断を足した

`LIST_SIZE` を大きくしたので、`CmdlistStorage` が確保に失敗する可能性がある。
失敗しても落ちはしないが**何も描かれない**ので、切り分けられるようにした。
組み込みの 120ms 後にノードを読み、`/CTRPF_OwnGui.txt` へ出す。

```
上ノード list=42 記録長=NNNN バイト
下ノード list=43 記録長=NNNN バイト
[!] コマンドリストを作れていない。LIST_SIZE(0x10000) が大きすぎる疑い。
```

### ビルド

**警告 0 件・エラー 0 件。** 776,884 バイトの `.3gx`。
ケーブ・TEV・日本語の文字列が埋め込まれていることをバイト列で確認した。

### まだ入れていないもの

- **自前キーボード**（利用者の指示により保留）
- リストボックスの画面表示（インラインリストは左右で切り替える形にした）
- ホットキーの入力待ちウィンドウ（Y で候補を回す形にした）
- PixelMplus10 の数字（いまは数値も美咲で描いている）

### 実機へ入れる前に

**先に 1 つ前の版を外すこと。** `.bss` の配置も `LIST_SIZE` も変わったので、
古い版が入ったままだと整合しない。
