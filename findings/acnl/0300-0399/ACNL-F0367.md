## F-341（2026-09-07）: 費用の式を「当てはめ」から「逆アセンブルの写し」へ

**confidence: HIGH**（実機 19 点で誤差 0。うち **3 点は式を書いたあとに予言してから測った**）
根拠: decompile（`BuildCommandStream 0x004D6570` / `sub_4D6CE0 0x004D6CE0`）+ memory 値
正本: `PATCHES/batch_cost_exact.py`（自己検査つき）。`batch_cost_model.py` は薄い転送に差し替え
詳細: `scratchpad/MEMO_f341_cost_exact.md`

### 計数器（F-337 の推定を 1 点訂正）

| 欄 | 増え方 | 吐き出しの条件 |
|---|---|---|
| `ctx+0x24` q | 字ごと +1 | `q > 25` |
| `ctx+0x26` p | 字ごと **+2** | `p > 30` → **16 字ごと** |
| `ctx+0x27` s | ★**色が「変わった」ときだけ +4** | `s > 24` → **色替え 6 回ごと** |
| `ctx+0x690` flag | 色が変わるたび 1 | 吐き出しで `s == 4` なら 0 |

★F-337 は `+0x27` を「色ブロックごと」と書いたが誤り。
**吐き出しをまたいで同じ色が続くときは増えない。** `s` は吐き出しのたびに 4 へ戻る。

### 1 回の吐き出しが積む語数（`sub_4D6CE0` の写し）

```
block A   16*q + 16 バイト = 4q + 4 語        必ず
色ブロック  flag のときだけ:
            batch+0x24 が 0 なら  s==4 -> 0 語 /  s>4 -> 4 + (4s - 16) 語
            そうでなければ                        4s + 4 語
block B   16*p + 16 バイト = 8q + 4 語        p != 0 のとき
末尾      4 語 + 固定 0x40（16 語）= 20 語
```

単色なら **12q + 28 語**。F-338 の「1 字 12 語 + 吐き出し 28 語」の正体。
頭の固定費は **ひな型 24 語 + 群のブロック 22 語**（F-340 の「74」は内訳が違っていた）。

### ★F-340 の式が 16 語ずれた理由

```
v65 = *(writer + 0x18);   v66 = *(writer + 0x1C);      ← 現在色の初期値
```

`BuildCommandStream` は現在色を **writer から**読む。表を回して描く実装では
writer に残るのは**最後の文字列の色**なので、
**1 字目の色がそれと違えば 1 字目で色替えが 1 回起きる（+16 語）。**
F-340 の 15 点はすべて「最初と最後が違う」条件で、16 点目だけ両端が白だった。

対照実験（**色の並びも字数も変えず、最後の 1 行の色だけ**変えた）:

| 条件 | 語数 | 記録長 |
|---|---|---|
| 86 字・色 7・最後=白=最初 | 1446 | 5984 |
| 同上・**最後の行だけ緑** | **1462**（予言的中） | 6048 |
| 24 字・3 字ごとに 8 色・最後は別色 | **542**（予言的中） | 2368 |
| 同上・**最後だけ 1 行目と同色** | **526**（予言的中） | 2304 |

### 実務用の費用

| 何 | 費用 |
|---|---|
| 字 1 つ | 12 語（48 B） |
| 吐き出し 1 回 | 28 語（112 B）。**16 字ごと**、または**色替え 6 回ごと** |
| 色替え 1 回 | 16 語（64 B）。ただし**吐き出しをまたいで同色なら 0** |
| 書体替え | **0**（同じアトラスなら群も切れない。F-339） |

安全弁は `batch_cost_exact.budget_words(色の連の列)`。
「最初と最後の色が違う」最悪を仮定するので**必ず過大側**（差は最大 16 語 = 64 B）。
