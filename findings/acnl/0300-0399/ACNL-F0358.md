## F-333（2026-09-07）: トグル実行エンジン（壁抜け仕様の一般化）

利用者の壁抜け例をそのまま一般化した設計。直接指示の書き換え許可あり。

### 仕様（壁抜け例）

- メニュー OFF ＋ホットキー → 何も起きない。
- メニュー ON ＋ホットキー → 効果が書かれていれば既定値に戻して
  無効通知、そうでなければ有効値を書いて有効通知。
  題はチート名。メニュー開閉中は発火しない。
- メニュー OFF 化 → 何もしない（書かれていても残す）。
  次の ON＋押下で読取検証により再同期する。

### 設計

- メニューのチェック（`applied`）はアーム専用。効果に直接触らない。
- `RegisterToggleEffect(番号, アドレス, 1/2/4, 有効値, 既定値)` で
  記述子を登録（`Unregister` まで残る。再有効化で登録し直し不要）。
  発火（閉鎖中・有効中の押下の立ち上がり）で読取検証→反転→
  書換＋`FlushMemory`（データ＋命令）→通知。
- 特殊な効果は `HotkeyHandler`（押下の横取り）/`OnTick`（毎フレーム）
  で自作する逃げ道を残した。`ToggleEffectActive()` で読取検証、
  `FlushMemory()` は自作側からも呼べる。
- 1/2/4 バイトの単一アクセス（整列していること）。`address == 0`・
  不正 size・範囲外番号の登録は拒否する。

### 実機で確かめること（壁抜けでの例）

1. OFF＋押下で何も起きないこと。
2. ON＋押下で書込み＋有効通知、再押下で復元＋無効通知（赤の帯・縁）。
3. 書込み済みのままメニュー OFF→ON→押下で、復元＋無効通知になること。
4. メニュー開閉中の押下で切り替わらないこと。

検証器 2 種 0 件、ビルド済み。ケーブ不変。
