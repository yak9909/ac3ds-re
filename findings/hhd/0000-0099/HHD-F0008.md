## IDA-opus-5.5-HHD-F003: キャラクリ画面のコード — 組み立て・絵の差し替え・色の反映・選択グループ（2026-10-05、MEDIUM: 静的のみ。実機未観測）

解析ソフト: IDA 9.3（idalib、`ida/db/hhd_jpn_v11.i64`）＋ objdump / 解析モデル: opus-5.5。根拠は逆アセンブル・文字列・静的初期化と資源の照合。
- 組み立て `CharaCreate_LoadArchivesAndBuildLayouts 0x1EE5B8`: 3 アーカイブと 5 レイアウトを専用クラスで作る（詳細は docs/hhd/chara_create_screen.md 2 章）。
  クラスは基底 `LayoutObj_BaseCtor 0x3432F0` の上に vtable 2 本（+0 と +8、offset-to-top −8）。顔 = vtbl 0x6E4E40 / 0x6E4F10、目の一覧 = 0x6E4160 / 0x6E4230。
  コンストラクタが読み込む vtable リテラル: 髪の一覧 0x6E4D64、背景 0x6E7F84、上画面 0x6E804C（+0 か +8 かは未確定）。
- 絵の差し替え: `EyeButtonPart_SetEyeTextures 0x3B1800` と `HairPageLayout_SetHairTexture 0x3BB190`。文字列の表は静的初期化で作られる
  （0x5C0568: g_EyeIconSexLetters 0x792E50 = {"B","G"}、g_PaneName_P_Eye_00 0x735108、g_PaneName_P_Iris_00 0x735110 / 0x5C2C4C: g_HairIconSexLetters 0x792F98、g_PaneName_P_Hair_00 0x735120）。
  文字列は PC 相対（`add rN, pc, #imm`）で、番地は Python で計算した。髪は番号 ≥ 16 で G の組。
- 色の反映: 部品の Set*Color 7 本（0x3B1968 / 0x3B19A4 / 0x3BB29C / 0x3BB2D8 / 0x3C0738 / 0x3C0774 / 0x3C07B0）が `LayoutObj_SetAnimSlotFrame 0x3534C4` で
  アニメ枠 11〜13 のフレーム = 色番号にする。枠と名前の対応は静的初期化の表（g_EyeButtonColorAnimNames 0x792E60 等）と BindAnims 3 本で照合。
  → 資源側で「色番号 = フレーム」（段々のキー、F002）と独立に一致。
- 選択グループ: `SelectGroup_Ctor 0x3B8BB8`（vtbl 0x6EB6E0）、`_Add 0x3B8A00`、`_Update 0x3B8A38`、`_SetSelected 0x3B8920`。容量 g_CharaColorGroupCapacity 0x65EDFC = {6, 16, 8}（資源の個数と一致）。
- IDB: 関数 34 件・グローバル 9 件を命名、注記 10 件、保存済み。
- 未確定: ボタンの状態機械（ボタン +388、イベント 0x790610 / 0x790640）、髪のページ送り、十字キーの移動規則、顔 ↔ 髪の切り替えの呼び出し元。
- 反証条件: 実機で色番号を変えてもアニメ枠 11〜13 のフレームが変わらない、性別 0 で G の絵が出る。
