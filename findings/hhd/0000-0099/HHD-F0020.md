## IDA-gpt-6.1-sol-HHD-F001: カタログの格子 Tum15・上段タブ・小分類・名前の吹き出し・NEW の動き（2026-10-07、MEDIUM: 静的のみ）

解析ソフト: IDA（idalib）/ 解析モデル: **gpt-6.1-sol（推論 max）**、Codex CLI のサブエージェントとして（依頼 work/codex/tasks/t022_tum15.md）。記録・採番・照合は親（opus-5.5）。対象 HHD v1.1（code.bin SHA-256 42a4e486…）。
詳細と全根拠は **work/evidence/hhd_decorate/tum15/report.md**（機械可読 tum15.json、PMF 復元 extract_state_pmfs.py ほか）。HHD IDB に命名 250・コメント 270（一覧 idb_changes.md。コメントの ID は親が F??? → 本 ID に置換）。
- 格子 ctl_Tum15_00 の状態 9 個の enter/exec/exit（静的初期化 0x5BA884 → ctor 0x61354C → PMF 表 0x663354 → vtable 0x6E8750）。横送りは Drag → Slide → Wait。通常の上段タブ切り替えは Tum15 Out → 表とアイコンの更新 → In（FastIn/FastOut/Swap は別経路で、標準資源では Swap = 品を部屋へドラッグする経路は成立しない）。
- ページ: 物理ページ 3 枚（L_Page_00/01/02、X = −288/0/288、幅 288）を ±1.6 幅を越えたら ±3 幅へ移して使い回す。**先頭・末尾は循環しない**（全体位置を [−幅×(総ページ−1), 0] に制限、端で L/R を拒否）。L = 前、R = 次。十字キーは直接のページ入力ではない（LOW）。
  PageSlider: 追従 ×0.2、刻み最小 0.5・最大 clamp(v,10,25)、離したときの速さ上限 25・フリック閾値 8（投影 v/0.05、±1 ページに制限）、ドラッグ開始 |dx| 累計 ≥ 0.05（8 px）。ページ表示 n/m は T_Page_01 / T_Page_00。
- マス: 15 個は**列優先**（X = −112..112 の 5 列 × Y = 56/0/−56、間隔 56）、当たり B_Btn_00 54×54。押している間 = touch（N_All Y 0 → −2、1 コマ）、離して決定 = touch_ok（Y −2 → 0、scale 1 → 1.04 → 1）+ select_ok（色）。選択中 = select（P_Type_00/01 の色、White alpha 0 → 255）。**テクスチャの差し替えは無い**（FLAN の textures が空）。
- 音（SLink → BCSAR で照合）: マスの選択 SE_SYS_BTN_STATIC_ACTIVE_S 0x01000225、決定 SE_SYS_UI_DECIDE_LONG 0x01000239（条件で SHORT 0x01000238 / 3RD 0x0100023C、条件の出所は LOW）、格子 In SE_SYS_UI_WIN_OPEN_2ND 0x01000233、前ページ SE_SYS_PAGE_DEC 0x0100023F、次ページ SE_SYS_PAGE_INC 0x0100023E、スライド SE_SYS_SLIDE 0x01000245、小分類の境界 SE_SYS_SLIDE_NEXT_CATEGORY 0x01000246。上段タブ（CatalogBase）の決定 SE_SYS_UI_DECIDE_1ST 0x0100023A、小分類 SE_SYS_UI_DECIDE_2ND 0x0100023B、模様替え画面 MainTop の L_Top_01 決定 SE_SYS_ICON_CATALOG 0x01000251。
- 決定から置くまで: `HHD_CatalogWindow_WaitExec` 0x36B0B4 が中央の枠の決定 pulse（ボタン +270）→ 索引表 Window+35100/+35104 → 品番 → Item（0x51510C）→ **0x4D00A0 → Room_PutFurnitureAuto 0x4CDB2C**（親が照合済み）。touch_ok の完了は待たない。
- 名前の吹き出し wit_Slct（WinItem）: 選択中のマスが変わったときだけ、名前の幅 + 32 の窓を「マス Y + マス高/2 + 窓高/2 − 2」に置き、左右 ±160 に収める。未表示なら In（in_name 4 コマ: scale 0.8 → 1、alpha 0 → 255）、表示中なら FastIn。消すのは Out（out_name 2 コマ）。音なし。
- NEW 印 P_New_00: 品番 [0x2000, 0x7FFE) で、セーブの集合 B なら amiibo の絵、集合 A なら New の絵（集合の意味は LOW）。移植では出さない方針。
- 親の独立照合（opus-5.5）: (1) 0x4D00A0 / 0x4D56AC の逆コンパイルと xref、(2) ctl_Tum15_00 / tum_Page15_00 の FLYT の L_Page・L_Tum の座標、(3) tum_15_00_touch の FLAN（Y 0 → −2、textures 空）。3 点とも一致。
