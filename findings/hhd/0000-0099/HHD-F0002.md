## IDA-opus-5.5-HHD-F010: 髪のページ送り — ドラッグ・弾き・滑りの規則（2026-10-05、MEDIUM: 静的のみ。定数はすべて逆アセンブルの即値・リテラル）

解析モデル opus-5.5。IDB に関数 30・状態のグローバル 9 を命名、注記 6、保存。
- 部品は 2 つ。**ページ送り `PageSlider`**（`PageSlider_Ctor 0x3470A4`、状態 Wait / Drag / Slide = `g_PageSlider_StateID_*` 0x798038 / 0x798068 / 0x798098）と
  **ドラッグの当たり `DragArea`**（`Page_00`、`DragArea_Ctor 0x3CB3F0`、状態 Wait / Select / OnTarget / Decide / Drag / Slide = 0x78E5A8〜0x78E698）。
  髪の一覧は `sub_35DBC4` で PageSlider を作り、枠 3 つ・Page_00・L/R のボタンを繋ぎ、**回り込みを切る（+172 = 0）**。
- タッチの座標（`TouchInput_Update 0x37ED04`）: +4 = (x−160, 120−y) 画素・中心原点、+20 = その ×0.00625 / ×0.0083333（−1〜1）。
- ドラッグに入る: 触れてから**正規化座標の横移動の累計 ≥ 0.05（= 8 画素）**（`DragArea_ShouldStartDrag 0x3E7B20`、しきい値 DragArea +452）。
- ドラッグ中（`PageSlider_StateDrag_Calc 0x346ADC` → `PageSlider_MoveBy` / `MoveByClamped 0x346460`）: ページは**指の横移動（画素）と同じだけ**動く。回り込みなしでは
  位置を [−幅×(n−1), 0] に収める（端で止まる。伸びて戻る動きは無い）。
  速さ（`DragTracker_Update 0x33D2B8`、+108）= 前 × 0.5 + 2.0 × |画素の移動量（2 次元の長さ）| を [0, 120] に。向き（+96）は 1 画素を超えて動いたときだけ更新。
- 離す（`PageSlider_BeginSlideFromRelease 0x34699C`）: v = min(速さ, 25)。**v ≥ 8 なら弾き量 = v / 0.05**（= 20v 画素）を向きに足し、
  目標 = round((今回の移動量 + 弾き量) / 幅) を −1〜1 に丸めて × 幅、さらに全体の範囲に収める。滑る速さ = clamp(v, 10, 25)。
- L / R・左右の端（`PageSlider_RequestPageStep 0x346228`）: 目標 ±幅、速さ 25（+96）。待ちのときだけ受け付け、端のページでは何もしない。
- 滑り（`PageSlider_StepSlide 0x346D4C` → `Math_ApproachDamped 0x455EF8`）: 毎フレーム d = (目標 − 位置) × 0.2、|d| < 0.5 なら 0.5 ずつ寄せて目標で止める、
  それ以外は |d| を速さで切って足す。目標に着いたら Wait へ。
- ページ幅（+124）= 枠 2 と枠 1 の x の差（`PageSlider_ResetLayout 0x346798`）。
- 未確認: 実機の HHD での体感（利用者の目で確かめる）。動かすたびに鳴る音（`sub_512FF4(dword_731E44)`）の中身。
