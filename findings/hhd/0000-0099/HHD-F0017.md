## IDA-opus-5.5-HHD-F017: ゴミ箱の当たりの判定（2026-10-07、MEDIUM: 静的のみ）

解析ソフト: IDA / 解析モデル: opus-5.5。T022 のゴミ箱の当たりを HHD と同じにするため。
- `TrashPart_Wait_Exec` 0x3DDC98 は部品 +244 の「落とし先」部品の状態が Select か（`DropTarget_IsSelected` 0x5698E8: 状態機械 +388 の今の状態 == 0x7994F0）を見て OnTarget へ。
- 落とし先の状態は 3 つ（静的初期化 sub_5BAD24）: Wait 0x7994C0 / **Select 0x7994F0** / UnSelect 0x799520。切り替え `DropTarget_UpdateSelect` 0x393CD8:
  Wait・UnSelect → Select = `DropTarget_IsPointInside` 0x3E7EC8（触れていれば Input_IsTouchingInside(入力, 当たり +240)、そうでなければ投影した点が当たりの中）か、タッチの押した瞬間が中。Select → UnSelect = 点が外へ。
- 当たりのペイン名は "B_Base_00"（静的な名前の器 sub_5C6AC4）。ゴミ箱の B_Base_00 は x origin = left、47 x 53、N_All の (0, −4) → 部品の位置 (−165, −96) を足すと中心座標 x [−165, −118] y [−126.5, −73.5]（tools/hhd/export_decor_trash.py が JSON から計算）。
- IDB: 上の 3 関数と 3 状態を命名、0x393CD8 に注記。
