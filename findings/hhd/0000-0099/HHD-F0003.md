## IDA-opus-5.5-HHD-F008: 髪・目の形の番号 → モデルのファイル（2026-10-05、MEDIUM: 静的のみ。ACNL のファイル名と照合）

- `PlayerHead_BuildPath 0x1DFA44`（命名）: 髪の番号 k → `Player/head_mdl/{boy|girl}%02d{a|b}.bch`。k >= 16 なら girl、番号 = k & 15（帽子の種類で a / b / bald / bald_ear）。
- `PlayerFace_LoadTexture 0x1DF100`（命名）: 目の形 = PlayerLook_GetEyeType → `Player/face_tex/{boy|girl}%02da.bch`。
- romfs: HHD v1.1 head_mdl = boy00〜15 / girl00〜15（a・b）、face_tex = boy00〜12 / girl00〜12。ACNL（基本版）head_mdl = boy00〜15 / girl00〜15（+ msd）、face_tex = boy00〜11 / girl00〜11。
- ACNL 側は `PlayerHeadBank_BuildPath 0x271DD0` が 髪型 % 17（17 以上で girl。16 / 33 は寝癖）→ **HHD の髪 k → ACNL の髪型 = k (< 16) / 17 + (k − 16) (≥ 16)**。目の形は 0〜11 が同じ名前。
- 未確認: 同じ名前のファイルが同じ見た目か（形式が BCH / BCRES で直接は比べられない。実機で利用者の目で確かめる）。目の色・肌の色・髪の色の並びの対応（ACNL のコードに HHD の色の値の表は無い。ACNL はモデルの絵や LUT 側の見込み）。
