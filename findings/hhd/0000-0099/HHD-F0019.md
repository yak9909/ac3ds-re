- **種類ごとの品の並び** `MainEditMgr_BuildKindLists` 0x1B222C（BsMainEditMgr のジョブ）: 種類 k = 0..0x40 ごとに品番 0x2000..0x3740 のうち **Item.bin（46 B/件）の種類のビット**
  （`ItemParam_HasKind` 0x4409AC: +32 + (k+4)/8 バイト目の第 7 − (k+4)%8 ビット。1 つの品が複数の種類に入れる）が立つ物を、Item.bin +0（s16）= ItemSort の位置で添字を付けたビット集合に入れ（`ItemSet_Add` 0x1C87E0）、
  持っている品の集合（sub_5425F0 = セーブ +259412）と重ね、位置の昇順に並べる。品番 = ItemSort[位置] + 0x2000（`ItemSort_GetItemAt` 0x1C879C）。場面 +1368 = 並び、+25180 = 種類の開始位置、+25312 = ページ数 ceil(n/15)。
  窓へは `CatalogWindow_SetLists` 0x36E70C（+35100 / +35104 / +35108）、品が 0 個の種類は種類の列から外す（`CatalogWindow_SetupKinds` 0x369764）。
  検算: 全品で ItemSort[Item.bin +0] == 自分（catalog_kinds.py の assert）。
