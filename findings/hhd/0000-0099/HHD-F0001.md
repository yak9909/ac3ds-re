## IDA-opus-5.5-HHD-F011: 慣性と、選択枠・ボタンの縞の合成（2026-10-05、MEDIUM〜HIGH: 静的 + HHD のスクショ 2 枚で合成の意味を照合）

解析モデル opus-5.5。IDB: `DragArea_SlideDecay 0x3E86AC` に注記。
- 慣性（DragArea の Slide）: 離したとき正規化の速さ（+112）> 0.08 なら、毎フレーム 向き × 速さ（画素）だけ動き、速さを 0.95 倍。+112 < 0.01 で止まる。触れたらやめる。
  （利用者は「漢字変換の候補欄と同じスクロール」を指定したので gohan はこれではなく ChatIme の算法を使う。記録のみ）
- 選択枠（目 W_Frame_00LT / 髪 W_Frame_00LT / 色見本 P_Frame_00）と下のボタン（P_Btn_00）の材質は
  「1 枚目 = 形（目・髪・色見本は A4、ボタンは BtnCmn）、2 枚目 = 縞（L4、繰り返し、ペインに投影、45° / ボタン 55°）、合成 色 = overwrite・α = min」。
  照合: HHD のスクショで、選択中の目の枠は 2 色の橙の斜め縞（select の黒色 255,70,0 と白色 255,35,0）、「けってい」は 2 色の水色の縞（黒色 120,245,240 / 白色 200,255,250）、
  「かみがた」は黒色 = 白色（200,28,0）なので縞が見えない → **色 = 白色 × 縞 + 黒色 × (1 − 縞)、α = 形** と解釈して矛盾なし。
- 縞は部品の loop（40 フレーム、2 枚目の SRT の平行移動 0 → −1、x・y とも）で斜めに流れる。ボタンの部品には loop が無い（縞は止まっている）。
- ACNL での作り方は IDA-opus-5.5-F082（TEV 2 段、窓は 4 枚の枠に分けて角ごとに SRT を解く）。
- **実機（2026-10-05、gohan 6ad1443）**: 利用者 全 PASS（縞が流れる・向きと細かさ・「けってい」の縞）。色見本は押している間、未選択なら白い縁・選択済みなら縞（HHD の touch は枠を出すだけで色を変えない）→ 仕様どおり。
