# モデルの一生（読み込み → Setup → 体 → 描画 → 破棄）と、借りた資源を壊さない規則

2026-09-28、IDA / opus-5.5。根拠は FINDINGS **IDA-opus-5.5-F057**（静的＋停止中の実機の読み取り）、F010 / F013 / F016 / F056。
どの物体（村の fgobj・家具・自前の体）が描いていても、モデルは同じ nw::gfx の資源と同じ後片付けを通る。例外に見えるものも、この表のどこかで分岐しているだけ。

## 1. 流れ

| 段 | 関数 | すること |
|---|---|---|
| 読み込み | `G3dResHolder_RequestLoad 0x317920` | CGFX ファイルをヒープへ（非同期。holder +260 = 状態） |
| Setup | `G3dResHolder_Setup 0x317958(holder, alloc, 別の holder, 1)` → `sub_4A5A74` | 辞書ごとに型別の Setup。第 3 引数があればその資源（LUT ファイルなど）で名前を引く |
| モデル | `sub_4A91A4` | +196 形状 `sub_4A9368`、+188 材質 `sub_4A530C`、+180 メッシュ `sub_4A8B44` |
| 材質 | `sub_4A530C` | 旗 +24: 0x100 テクスチャ / 0x80 シェーダ（+644）/ 0x200 TEV の参照表（+648 → +40）/ 0x40 済み |
| 参照を結ぶ | `sub_4A6A7C` → `sub_4A6DFC` | 参照（型 0x40000000）の +4 ファイル名・+8 名前で引き、**+12 に相対を書く**。見つからなければ 0x80000004（旗を立てない） |
| 体を作る | `ModelInstance_Create 0x4F048C(holder, res, alloc, alloc, mask, …)` → `sub_4AF068` → `sub_4ADBAC` → `0x4ADD44` | mask に応じて材質の写し（本体 728 B・マッパー・TEV）を作る。mask 0 / 0x1000 は簡易の書き出し、ほかは汎用（F013） |
| 描く | 書き出し `0x4A17B8`（簡易）/ `0x49C08C`（汎用）→ `SendFragmentLuts 0x4B09F4` | 参照表を辿って LUT を送る。**+12 = 0 の参照に当たると 0x4B0C54 で落ちる** |
| 体を壊す | `ModelInstance_Destroy 0x4F053C` → Material dtor `0x4AF288` → `sub_4AE2A4` | 写しごとに Cleanup（参照を外す）と解放 |

## 2. 写しと後片付けの対応（mask ごと）

| mask | 写すもの | 壊すときに辿る先 |
|---|---|---|
| 本体（必ず） | 728 B。+628〜+648 の相対は 0 にしてから必要な物だけ入れ直す | `sub_13B7EC`: 写しの旗を落とす |
| 0x20 | テクスチャマッパー（参照テクスチャ 0x20000004 ごと `sub_4A5900` で新しく） | 写しの参照テクスチャの +0x1C = 0（`0x4A8490`）。**元の資源には届かない** |
| 0x40 | +640 | 同上 |
| 0x780 | TEV 244 B（0x100 が無ければ TEV +40 = 0） | **写しの +648 の TEV → +40 の表 → 各参照を +12 = 0（`sub_4A7420`）、さらに表・参照・TEV を alloc で解放（`sub_4AE958`）** |

★TEV を写さない（0x780 なし、例: 0x834）とき写しの +648 は 0（0x4ADEEC）。**ここに何かを繋いだまま壊すと、繋いだ先の表と参照をゲームが外して解放する。**

## 3. 借りた資源（季節資源など）を使うときの規則

1. 体を作るのは自由（写しは体のアロケータに作られる）。
2. **写しの材質から借りた資源の中身（表・参照・TEV）を指したまま体を壊さない。** 壊す前に自分で繋いだ所を元（0）へ戻す。
3. 借りた資源そのもの（ResMaterial の +24 / +32 / 参照表）へは書かない。書く必要があれば必ず戻す（MapEditor3D の層の変更は戻し表つき）。
4. 異常を疑ったら `tools/dynamic/scan_res_bindings.py`（停止中の実機で読み取りのみ）で、資源の全モデル・全材質の参照の結び付きを数える。
   正常なら LUT 参照もテクスチャ参照も外れは 0（2026-09-28 のクラッシュ時: 季節資源で 10 個 = 5 モデルだけ外れていた）。

- `sub_13B7EC` の +644 シェーダ参照（+28 = 0）と +628〜+640 のマッパーの後片付けは、写しに入れ直した物だけに届く（0x4ADD44 が 0 にしてから入れ直すため）と静的に見ている。
