# スコップ アニメーション再生速度

## 仕組み

`Actor_PlayAnim` (`0x0068D0EC`) の VFP 引数で速度が渡される。

```
R0 = actor,  R1 = アニメID (g_AnimNameTable の index)
S0 = 開始フレーム,  S1 = 再生速度(通常 1.0),  S2 = ブレンドフレーム(通常 5.0)
```

`S1` の `1.0f` は関数末尾のリテラルプールに `3F800000` として置かれる。
**その上位ハーフワードだけを 16bit 書き込みで差し替える**と速度倍率が変わる。

| 書込値 | 倍率 |
|---|---|
| `3F00` | 0.5x |
| `3F80` | 1.0x（既定） |
| `4000` | 2.0x |
| `4040` | 3.0x |
| `4080` | 4.0x |
| `4180` | 16.0x |

## 補足

- `0x66930A` は `[R4+0x8D0]` の条件分岐で `scoop_dig1`(73) と `scoop_stump1`(76) を
  兼ねる。1アドレスで2動作。
- `0x682470` は `S16` にロードされ `VMOV.F32 S1,S16` 経由で `0x682358` と `0x6823A4` の
  **両方**の呼び出しに効く。
- `0x65EF50` を参照する命令は `0x65EC60` の1箇所のみ。他アニメへの影響なし。
- `scoop_dig1` と `scoop_suka1` などは呼び出し経路が2つあるものがある。
  体感上すべてを速くするには両方を書き換える必要がある。

## 走査範囲

`Actor_PlayAnim` への BL は `0x600000`-`0x6C0000` を走査して 250 件検出、
うちスコップ帯(animID 71-79)が上記。`0x100000`-`0x600000` は**未走査**。
