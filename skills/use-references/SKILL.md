# 参考資料の使い方

- 資料の本体は `_local/refs/`、一覧と出所は `meta/references.toml`。
- 参考資料だけを根拠にした結論は LOW。IDB の一次証拠で裏を取ってから MEDIUM 以上にする。
- チートの名前は作者の主観。名前どおりの意味だと決めつけない。
- 1つのチートの全ての行が、その機能に関係するとは限らない。
- 他のビルド（地域・版）向けの資料のアドレスは、そのままでは使えない。対応する場所を一次証拠で探す。
- 記録には資料の名前（`meta/references.toml` のキー）と、使った箇所を書く。資料の本文を長く引用しない。
