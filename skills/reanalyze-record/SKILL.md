# 再解析

1. 対象の記録を `kb.py show` で読み、結論を「確かめる主張」の一覧にする。
2. 記録の根拠を信じず、IDB の作業用コピーで一次証拠（命令・呼び出し関係・データ）から主張を1つずつ確かめる。
3. 結果を新しい記録にする（`supersedes` に元の記録の ID）。
   - 全て確かめられた: 本文に「再解析で確認」と書き、確度を付け直す。
   - 一部が誤り: 正しい結論を書き、誤っていた点を「反証条件・未確認点」の前に「訂正」として書く。
4. 報告の「訂正の提案」に、元の記録 ID と結果（確認・一部訂正・反証）を書く。
