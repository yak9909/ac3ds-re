# 報告

`.task/report.md` に次の見出しで書き、呼び出し元には「完了」「中断」「失敗」のどれかと1行の要約だけを返す。ファイルを書けない環境では、同じ見出しの全文を最終の返答として返す。変更したファイル・記録の一覧・symbols の差分は書かない（差分から自動で作られる）。

```markdown
## 結果
完了 / 中断 / 失敗。完了条件のどこまでできたか

## 結論と根拠の要約
記録 ID ごとに1〜2行

## 訂正の提案
既存の記録・名前と食い違った物（ID と、どちらが正しいと考える理由）。無ければ「なし」

## 統合・重複の提案
同じ内容の記録、topics にまとめられる記録。無ければ「なし」

## 新しいタグの提案
タグ名と説明。無ければ「なし」

## 未確認点
実機で確かめるべき事を含む

## 次の1手
```

- 中断したときは、`.task/notes.md` に経過を残し、「次の1手」をそこから再開できるように書く。
