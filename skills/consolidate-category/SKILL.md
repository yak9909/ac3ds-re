# 消化

1. `findings/<スコープ>/by-category/<カテゴリ>.md` で未消化の記録を確かめ、`kb.py show` で読む。
2. `topics/<スコープ>/<カテゴリ>.md` を更新する。
   - 話題ごとに見出しを立て、結論・確度・根拠の記録 ID（`[ACNL-F0412]`）を書く。根拠そのものは写さない。
   - 矛盾する記録は両論を併記し、「矛盾」と書く。
   - 格付け C と ? の記録だけで支えられた結論は、「要確認」と書く。
3. 記録の管理項目（`state` など）は書き換えない。統合した記録・重複している記録は、報告の「統合・重複の提案」に書く。
